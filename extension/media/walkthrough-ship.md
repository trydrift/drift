# Ship

After review, Drift pushes the fix branch and raises the pull request.

If you have the GitHub CLI installed and signed in, Drift opens the pull request
itself and hands you the link. If you don't, it opens GitHub's own pull request
page for the branch instead — the branch is pushed either way, so nothing is
stranded. The GitHub CLI is an optional shortcut, never a requirement.

Drift never merges. The final decision stays with you.

# Evidence

Open the Drift report to see why each finding exists.

Drift combines computed API surface diffs where the ecosystem supports one
with release notes, changelogs, registry metadata, advisories, and migration
guides. Every finding links back to the evidence that produced it, and
anything Drift couldn't verify is shown as a gap rather than treated as safe.

The report then connects those upstream changes to the exact files and lines
in this repository that use them.

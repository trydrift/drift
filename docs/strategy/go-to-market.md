# Go To Market

## Wedge

Start with teams that already run Dependabot or Renovate but close many upgrade
PRs because nobody can tell whether the breakage is real. Drift should turn
"major upgrade anxiety" into a reviewed plan with citations, gaps, and bounded
verification.

## Adoption Path

1. Local CLI and VS Code extension for individual developers.
2. Free hosted public-repository analysis, abuse-limited.
3. Team app for private repositories, scheduled analysis, dashboards, policy,
   and shared migration memory.
4. Enterprise self-host/VPC for private registries, compliance, data residency,
   custom analyzers, model policy, and managed modernization.

## Sales Motion

Developer-led adoption should prove the value: fewer stalled dependency PRs,
clearer review packets, and less agent sprawl. Team conversion adds private-repo
automation and collaboration. Enterprise conversion adds governance and
deployment control.

## Rollout Guardrails

Never claim universal behavioural compatibility, full semantic reachability, or
production safety. State what was checked, what was not checked, what evidence
supports the finding, and what verification ran.
